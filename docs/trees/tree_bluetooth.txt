# /vipxpert_minimal_os/docs/trees/tree_bluetooth.txt
/vipxpert_minimal_os
├── vipxpert_os.service (Systemd configuration for automatic boot execution and persistence)
    └── /src
        ├── /core
            ├── bluez_avrcp_patch.py (Idempotent binary patcher for /usr/libexec/bluetooth/bluetoothd on aarch64 replacing b.hi 0x5121c at 0x511fc with NOP so avrcp_get_item_attributes_rsp always falls through to avrcp_get_element_attributes PDU 0x20 on the AVRCP Control channel, preventing Android Browsing 0x73/0x71 NowPlaying stubs from wiping Title/Artist/Duration)
                └── -> ensure_bluez_avrcp_patch() (Verifies and self-heals the 4-byte 0x511fc NOP patch on daemon startup with automatic .bak backup)
            ├── bluetooth_daemon.py (Background service managing BlueZ DBus connections and Agent lifecycle; invokes ensure_bluez_avrcp_patch() on boot and caches active Title/Artist to /tmp/vip_bt_track_cache.json across service restarts)
                ├── -> PairingAgent (DBus Agent that intercepts BlueZ pairing and authorization requests and routes them to the UIManager)
                    ├── RequestConfirmation() (Intercepts pairing attempts, instantly auto-rejects blacklisted MACs, tracks `_pending_future`, and mounts ConfirmModal while saving explicit user rejections to the database)
                    ├── Cancel() (Cancels `_pending_future` and morphs pending/active pairing modals into missed notifications on kernel timeout)
                    └── AuthorizeService() / RequestAuthorization() (Silently auto-approves A2DP audio and HFP call profiles for trusted devices)
                └── -> BluetoothDaemon (Initializes DBus, executes boot-time hardware and volume sweeps, manages Match Rules, disk-caches codecs, and acts as an active AVRCP transmitter while defending against phone volume overwrites)
                    ├── start() (Connects to system DBus, registers the agent, seeds connected_mac and bt_session_connected=True / bt_user_disconnected=False from existing org.bluez.Device1 connections on boot, mounts signal matchers including org.bluez.Device1 PropertiesChanged, and executes dynamic boot-time power-on loops across all available adapters to bypass crashed chips)
                    ├── _parse_media_properties() (Safely unpacks BlueZ media Variants, latches elapsed position on pause transitions, resets duration=0.0 on Title change when Duration is omitted, preserves existing Title/Artist on partial Duration/Item AVRCP Track updates while updating /tmp/vip_bt_track_cache.json, clears Artist on full Title changes that omit Artist, and triggers _update_pipewire_codec() only on Status/Track changes)
                    ├── _reset_media_state() (Forcefully clears media caches, unlinks /tmp/vip_bt_track_cache.json, dynamic paths, transport states, and reverts status to 'stopped' when a device disconnects or drops connection)
                    ├── _dbus_signal_handler() (Intercepts org.bluez.Device1 Connected state changes—setting bt_session_connected=True / bt_user_disconnected=False and firing bt_connect chime on connect, or marking bt_user_disconnected=True and firing bt_disconnect chime only on clean HCI disconnect when _bt_recovering is False and /sys/class/bluetooth/hciX is still present—alongside BlueZ track changes, A2DP transport states [accumulating elapsed position on State='active'], and the Absolute Volume "Defender" script)
                    ├── _update_pipewire_codec() (Asynchronously queries the user-session PipeWire server via pw-dump using a strict active-stream guard to prevent idle fallbacks from corrupting the persistent codec_cache.txt)
                        ├── send_media_command() (Acts as a DBus transmitter to send AVRCP playback control signals like Next, Previous, Play, and Pause to the dynamically tracked phone)
                        ├── adjust_bt_volume() (Sends strict, absolute volume write commands to the active MediaTransport1 path, gracefully failing if the phone disables Absolute Volume sharing)
                        ├── read_codec_config() (Parses active bluez5.codecs and AAC/LDAC quality flags directly from 53-no-hearing-protection.conf as the single source of truth)
                        ├── apply_codec_rules() (Updates monitor.bluez.properties in 53-no-hearing-protection.conf, dynamically manages 'msbc' in bluez5.codecs and bluez5.enable-msbc based on mic_mode, synchronizes controller SCO MTU to 60:12/48:12, purges conflicting overrides, and restarts PipeWire/WirePlumber)
                        └── cleanup() (Gracefully tears down DBus connections, removes signal matchers, and unregisters the agent to prevent orphaned BlueZ paths on hotplug)
                    ├── _apply_bt_stream_volume() (Asynchronously polls pw-dump with XDG_RUNTIME_DIR, caching the bluez_input stream ID globally, and safely scales or enforces a 1.29x volume baseline after a 1.0s graph-build delay)
                    └── _ghost_watchdog_loop() (Background watchdog that skips active RF polling when bt_user_disconnected is True or when A2DP transport_state == 'active' (preventing 15s l2ping L2CAP/USB packet jitter during audio playback), pings idle connected_mac or player_path via l2ping -c 1 every 15s, re-verifies no clean disconnect arrived mid-ping, and on silent phone/radio crash preserves bt_session_connected=True, clears stale media state, and triggers OSKernel._debounce_bt_restart() to heal and auto-reconnect)
        └── /apps
            ├── bluetooth_app.py (Front-end interface for BlueZ visibility and device management)
                └── -> BluetoothBlockedApp (Sub-menu displaying blacklisted devices fetched directly from the SQLite database)
                    ├── _refresh_blocked() (Populates the list with blacklisted MACs and device names)
                    └── _prompt_unblock() (Summons ConfirmModal to delete a device from the blacklist database)
                ├── -> BluetoothManagerApp (Main Hub managing global radio power, 4-state discoverability timers including Smart mode, auto-connect policies, and active audio stream info)
                        ├── _check_power_state() / _toggle_power() (Dynamically scans and toggles all BlueZ adapters natively via DBus, bypassing hardcoded paths to gracefully ignore crashed onboard hardware)
                    ├── _prompt_disconnect() (Summons a ConfirmModal to drop the active Bluetooth connection, setting bt_user_disconnected=True and bt_session_connected=False before invoking bluetoothctl disconnect so the watchdog and recovery daemons respect the manual disconnect)
                    ├── _countdown_task() (Independent asyncio background task enforcing the visibility timer regardless of app focus)
                    ├── _sync_hardware_visibility() / _toggle_visibility() (Cycles 4 visibility modes and pushes states to BlueZ, resolving Smart mode logic based on active connections)
                    ├── _toggle_autoconnect() (Cycles through auto-connect policies like Off, On Boot, and On Plug)
                    ├── _toggle_mic_mode() (Cycles microphone profile between 16kHz mSBC wideband speech and 8kHz CVSD narrow-band, updating WirePlumber and controller scomtu on the fly)
                    ├── on_start() (Asynchronous startup hook to fetch DBus states prior to initial rendering)
                    ├── _fetch_async_state() (Gathers adapter power and active device DBus states asynchronously, triggering hardware pushes if Smart mode detects connection changes)
                    ├── _rebuild_menu() (Synchronously constructs the dynamic UI list using pre-fetched async state data)
                    └── update() (1s telemetry hook forcing UI redraws for active countdowns and executing non-blocking background DBus polls)
                ├── -> BluetoothDevicesApp (Sub-menu parsing trusted DBus devices)
                    ├── on_start() (Asynchronous startup hook to ensure devices are fetched before rendering)
                    ├── _refresh_devices() (Asynchronously extracts trusted MAC addresses natively from BlueZ DBus to prevent subprocess freezing)
                    └── _mount_device_actions() (Instantiates an inline context menu to manage a specific device)
                ├── -> BluetoothDeviceActionApp (Context menu for setting Primary targets, connecting, and deleting specific devices)
                    ├── on_start() (Binds 'Set Auto Primary', 'Connect Now'—which clears bt_user_disconnected=False before invoking bluetoothctl connect—and 'Forget Device' actions for the selected MAC)
                    └── _prompt_forget() (Summons global ConfirmModal overlay to untrust a device)
                ├── -> BluetoothCodecApp (Sub-menu for dynamic FiiO-style Bluetooth codec toggling utilizing an exhaustive God Mode plugin wishlist with local pending states)
                    ├── on_start() (Fetches fresh database codecs and seeds the local state on load)
                    ├── _rebuild_menu() (Constructs the visual checklist based on pending memory states)
                    ├── _toggle_codec() (Flips the local codec state without touching the DB or daemon)
                    └── handle_key() (Intercepts the back button to conditionally trigger the save modal, strictly synchronizing original and pending states upon resolution to plug memory leaks and prevent zombie modal loops)
                └── -> BluetoothQualityApp (Sub-menu for configuring advanced AAC and LDAC codec quality settings with local memory tracking)
                    ├── on_start() (Fetches fresh database quality flags and seeds the local state on load)
                    ├── _rebuild_menu() (Constructs the visual checklist based on pending memory states)
                    ├── _toggle_quality() (Flips the local boolean state for codec qualities)
                    └── handle_key() (Intercepts the back button to conditionally batch-save to DB and trigger daemon restart via ConfirmModal, safely resetting internal dirty flags upon resolution to prevent infinite modal persistence)
