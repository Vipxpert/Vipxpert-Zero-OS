# /vipxpert_minimal_os/docs/trees/tree_ir.txt
/vipxpert_minimal_os
├── vipxpert_os.service (Systemd configuration for automatic boot execution and persistence)
        ├── /hardware       
            └── ir_transceiver.py (Hardware abstraction for LIRC infrared transmission/recording)
                └── -> IRTransceiver (Wraps ir-ctl v4l-utils toolkit asynchronously with dynamic device routing)
                    ├── _probe_hardware() (Dynamically scans /dev/lirc* features via subprocess to assign correct tx/rx nodes)
                    ├── is_ready() (Verifies if IR rx/tx nodes are successfully identified)
                    ├── send_raw() (Translates math symbols to lirc syntax and executes via RAM-backed temp files to bypass stdin limitations)
                    ├── _fuzzy_match_signals() (Mathematical heuristic comparing pulse counts and temporal durations within a ~20% tolerance to safely verify identical IR patterns)
                    ├── receive_raw() (Records raw incoming IR pulses, utilizing an injected asyncio.Event for instant hardware lock cancellation and intercepting stderr to bubble exceptions)
                    ├── parse_pulses() / decode_protocol() (Parses raw microsecond pulse/space timings and automatically decodes NEC, NEC Repeat, Samsung, Sony SIRC 12/15/20-bit, Philips RC5, and RC6 hex addresses/commands)
                    └── stream_raw_continuous() (Continuously yields raw IR pulse/space timings or 150ms silence boundaries for the real-time Mode2 IR logic analyzer)
        └── /apps
            ├── ir_app.py (Stateful controller app acting as a dynamic router for the IR subsystem)
                ├── -> IRRootApp (Custom root app subclassing CrudListApp acting as the visual hub, managing its own hardware safety and Wi-Fi state lifecycle)
                    ├── _prompt_wifi_disable() (Safely checks and mounts a confirmation modal to disable Wi-Fi for IR timing accuracy on entry)
                    ├── on_start() (Triggers the initial Wi-Fi prompt on fresh boot)
                    ├── on_resume() (Context-aware wakeup hook utilizing the previous app ID to selectively prompt Wi-Fi only when entering top-down)
                    └── handle_key() (Intercepts the 'D' button at the root level to intelligently check and prompt Wi-Fi restoration via ConfirmModal on exit)
                └── -> IRControllerApp (Provisions CrudListApps on the fly to seamlessly handle IR hardware logic and SQLite data, acting strictly as an invisible UI router)
                    ├── on_start() (Initializes and mounts the visual list instantly without blocking for UI overlays)
                    ├── _check_wifi() (Polls the kernel via nmcli to track the actual Wi-Fi radio state)
                    ├── _set_wifi() (Executes sudo nmcli radio toggles securely)
                    ├── update() (Smart Wake: Re-routes instantly to the remotes hub if pulled from background cache)
                    ├── _mount_remotes() (Instantiates the custom IRRootApp for devices, dynamically injecting the Test Receiver hardware diagnostic tool)
                    ├── _launch_tester() (Spawns the raw IR oscilloscope UI directly from the root hub)
                    ├── _mount_commands() (Builds the nested CrudListApp for specific payloads, defining custom LEARN mode logic)
                    ├── _fire_payload() (Executes raw IR transmission utilizing the unified blocking and info toast UI API)
                    └── _do_learn_capture() (Executes advanced multi-stage IR clustering, hijacking a ConfirmModal to provide instant hardware cancellation and dynamic UI feedback across up to 8 fuzzy-matched capture attempts)
            ├── ir_test_app.py (Real-time IR Oscilloscope diagnostic tool for tracking RF/Plasma interference and testing hardware health)
                └── -> IRTestApp (Live Mode2 square-wave logic analyzer and NEC/Samsung/SIRC/RC5/RC6 protocol decoder with timeline pan/zoom and Pin 31 TX replay)
                    ├── _read_stream() (Background task consuming the hardware generator, formatting pulse lists, and triggering layout redraws upon silence cutoffs)
                    └── _draw_state() (Overrides default compositor to paint the text layout and inject a solid hardware flash indicator block on active signals)
├── ir_analyzer.py (Standalone diagnostic tool for single-stage IR signal capture and temporal healing)
    └── run_analyzer() (Captures raw IR stream, sorts durations to find noise gaps, and reconstructs fragmented timelines)
├── ir_analyzer_duration.py (Standalone diagnostic tool for two-stage true-baseline IR noise filtering)
    ├── capture_stream() (Asynchronously records raw IR pulses for a specified duration and prompts user)
    └── run_analyzer() (Executes Phase 1 ambient baseline capture, then Phase 2 payload capture applying the measured noise ceiling)
├── ir_timeline.py (Standalone diagnostic tool mapping 10-minute continuous IR noise profiles and performing Wi-Fi/BT RF interference baseline comparisons)
