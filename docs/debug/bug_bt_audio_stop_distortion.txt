# Stage: Symptom & Target Invariant [RESOLVED]
Bluetooth audio stops during Bad Apple MV when I2C0 collisions/resets disturb PCM5122 (0x4C) or USB BT hotplug misclassifies adapter reset as user disconnect; audio distorts if non-integer OSR divider (111=/112=877.7kHz) + NOS (prog 7) is active, or rhythmic "rrrrrr" occurs if 98.304MHz PLL (R=2) is paired with Reg 0x25=0x08 (Auto clock error detection enabled). Target: continuous undistorted audio with synchronous 98.304MHz PLL (dac_div=0, ncp_div=127, osr_div=127 -> 768kHz=16xFs, prog=1, Reg 0x25=0x0A). Status: RESOLVED (8-msg 0x90 full-screen MV chunks, post-spin shm[12:16] abort, range(2) NXP 9-SCL unwind + finally shm[32:36] DAC notification, STOP-separated 100kHz 0x59 INA219/PCM5122 reads with TWI0_SRST recovery, and Core-3 SSH/VS Code isolation).
